# Security and Governance

## Overview

The platform implements Snowflake-native security controls to protect sensitive data and enforce least-privilege access.

---

# Security Components

* RBAC
* Secure Views
* Masking Policies
* Row Access Policies

---

# RBAC

Roles are assigned based on responsibilities.

Implemented roles:

* DATA_ENGINEER_ROLE
* BI_ANALYST_ROLE
* AUDITOR_ROLE

---

# Secure Views

Secure views expose curated data while protecting underlying objects.

---

# Masking Policies

Sensitive fields are dynamically masked based on user roles.

---

# Row Access Policies

Users can be restricted to specific subsets of data.

---

# Governance Objectives

* Data Protection
* Compliance
* Auditability
* Controlled Access

---

# Benefits

* Reduced risk
* Better governance
* Enterprise readiness
