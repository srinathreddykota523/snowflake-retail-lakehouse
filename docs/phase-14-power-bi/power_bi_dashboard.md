# Power BI Dashboard

## Overview

The Power BI dashboard provides business and operational insights using the MART layer of the Retail Lakehouse Analytics Platform.

The dashboard consumes curated analytical datasets generated through dbt and Snowflake.

---

# Dashboard Pages

## Executive Summary

Provides high-level business metrics.

KPIs:

* Revenue
* Orders
* Average Order Value
* Customer Count

---

## Customer Analytics

Provides customer-focused insights.

Examples:

* Geographic distribution
* Repeat customers
* Customer revenue

---

## Product Analytics

Provides product performance analysis.

Examples:

* Category revenue
* Top products
* Product trends

---

## Operational Analytics

Provides platform visibility.

Examples:

* Warehouse utilization
* Query performance
* Resource consumption

---

# Data Sources

The dashboard uses:

* FACT_ORDERS
* DIM_CUSTOMERS
* DIM_PRODUCTS
* DIM_DATE
* DIM_PAYMENTS
